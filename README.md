# Estudo · Avaliação e Desempenho de Sistemas Computacionais

Site interativo de estudo para a disciplina **ADSC**, feito a partir das apostilas das Semanas 1 a 6, da Atividade da Semana 6 e da Atividade de Revisão (Profa. Edna Ramos).

🔗 **Acesse:** https://luan-k10.github.io/estudo-avaliacao-desempenho/

## O que tem

- **Resumos** das 6 semanas, com tabelas, fórmulas e pegadinhas de prova
- **Fórmulas**: um resumo de uma página com tudo que costuma cair
- **Quiz**: 166 questões com explicação, filtros por semana, "não respondidas" e "revisar erradas"
- **Simulado** cronometrado com nota e correção comentada
- **Flashcards** para revisão rápida
- **Discursivas**: questões das atividades com resposta-modelo e checklist de pontos-chave
- **Laboratório**: calculadoras de utilização/vazão, fila M/M/1, Lei da Utilização (gargalo), Lei de Little, disponibilidade (nines), matriz de decisão ponderada, CPU/AMAT e métricas de rede

Seu progresso e suas respostas ficam salvos no navegador (localStorage).

## Tecnologia

HTML, CSS e JavaScript puros, sem build. O visual segue o design do meu [portfólio](https://luan-k10.github.io), e o layout foi feito primeiro para celular.

Para rodar localmente, basta abrir `index.html` ou servir a pasta:

```bash
python -m http.server
```
